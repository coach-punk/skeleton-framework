Skeleton Framework Templates

A lightweight, mobile-first CSS boilerplate built with modular CSS Custom Properties (src/core/_root.css), a 12-column responsive grid, and accessible :focus-visible defaults. Use the examples below as copy-ready building blocks for landing pages, dashboards, and documentation sites.

Explore Grid Layouts View on GitHub

Quick Start

Link dist/skeleton.css or dist/skeleton.min.css and wrap content in .container and .row.

8. Lists, Native Disclosures & Custom Theming

Unordered & Nested Lists

  • Modular source files in src/core/
    • _root.css for CSS Custom Properties
    • _grid.css for 12-column responsive layout
    • _buttons.css and _forms.css with :focus-visible
  • Compiled with PostCSS 8 and minified via esbuild
  • Zero high or critical dependency vulnerabilities

Ordered Workflow & Native Accordion

  1. Edit design tokens or rules in src/core/_*.css
  2. Run npm run build (or npm start for live watch + serve)
  3. Include dist/skeleton.min.css in production
How do I customize the grid width or gutter?

Override --max-width, --total-columns, or --gutter inside a :root block in your stylesheet.

Are legacy browsers supported alongside CSS Variables?

Yes. The build pipeline runs postcss-custom-properties({ preserve: true }) so every rule includes both a static fallback and the dynamic var(--*) declaration.

Custom Theme Override Example (<pre><code>)

:root {
  --max-width: 1140px;
  --gutter: 1.25rem;
  --link-color: #0FA0CE;
  --primary-button-background-color: #1EAEDB;
  --primary-button-background-color-enter: #157b9b;
  --border-radius: 6px;
